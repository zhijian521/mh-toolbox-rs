# 目标页的养成范围

目标先选一个或多个角色，再选养成项目与目标值。多人养成要求每名适用角色分别达到目标，
进度直接读取角色档案；后续新增角色不会自动加入已有目标。

| 养成分类        | 可选择项目                                             | 进度来源      |
| --------------- | ------------------------------------------------------ | ------------- |
| 人物修炼        | 攻击、防御、法术、抗法、猎术修炼                       | 角色修炼      |
| 召唤兽修炼      | 攻击、防御、法术、抗法控制力、育兽术                   | 角色宠物修炼  |
| 师门技能        | 所选角色门派的技能及已录项目                           | 角色师门技能  |
| 生活技能        | 强身术、冥想、打造、烹饪、强壮、神速等完整技能名录     | 角色辅助·生活 |
| 剧情技能        | 变化之术、仙灵店铺、奇门遁甲等完整技能名录             | 角色辅助·剧情 |
| 角色属性        | 气血、魔法、伤害、防御、速度、法伤、法防、加点、帮贡等 | 角色属性      |
| 角色等级        | 等级                                                   | 角色档案等级  |
| 乾元丹 / 潜能果 | 乾元丹数量、潜能果数量                                 | 角色属性·潜能 |

生活、剧情与门派技能来自已有游戏数据表，不另维护一份技能清单。未录项目显示待补录，仍计入目标分母。
更新进度填的是当前实际值，保存后直接同步角色档案；缺少的辅助、修炼、属性行按正确组补入。
未触碰的未知值不会自动记成零。师门项目不允许写到其他门派的角色；换门派后不再适用的行保留展示，
不参与达标计算。全部成员已删除或均不适用时，目标保持未完成。

## 尚未建档的养成

梦幻西游还包含坐骑等级与成长、坐骑技能、法宝修炼、神器养成、装备宝石锻炼、灵饰精炼、
召唤兽等级 / 资质 / 成长 / 技能培养等。当前没有为这些项目建立完整的自动关联，统一使用「手动」目标：
填写名称、目标与单位，再增加或减少进度，支持两位小数。多个关联角色共用这条目标的累计值；
需要分别跟踪时，各建一条单角色目标。

「装备」继续用于累计购入件数，「存钱」用于元或万的累计目标，与账号、收益账本保持独立。
这三类手动目标的记录均可删除，进度随之重算。手动目标从零累计，已有进度可作为第一条记录录入。
