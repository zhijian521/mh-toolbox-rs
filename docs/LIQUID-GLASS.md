# Liquid Glass 分支开发指南

`codex/liquid-glass-shell` 在现有 Windows 桌面应用内重做界面，采用 mac 风格的玻璃表面、底部 Dock 和明暗壁纸。玻璃界面和账簿界面共用业务模型、保存服务与本地 SQLite 账本。桌面窗口里的记价、导入和恢复都会操作当前账本。

## 从哪里看效果

- **总览**：打开默认的 `#/overview`。可看工作台近一周和近一个月的统计、七天收益趋势、队伍近期记录及进行中的目标。
- **物价**：在本分支运行 `npm run dev`，打开 `http://127.0.0.1:5173/#/prices`。这里可以看业务卡片、分类筛选、记价与历史弹窗怎样组合。
- **组件目录**：打开 `#/components`，或在 Dock 上连续快速点击五次「设置」。目录采用设置式左右布局：左侧分为卡片、按钮与菜单、输入控件、选择控件、容器与表面、反馈与弹层，右侧独立滚动展示当前分类。切换保留示例值和各分类滚动位置，支持上下方向键及 Home／End。目录里可以试用输入框、数字输入、日期、价格、紧凑开关、固定表头、紧凑分页、菜单、弹层和空状态。数字输入同时展示两档尺寸、错误和禁用状态。物价示例使用内存数据。
- **统一材质**：整个玻璃界面使用清透折射。按钮和 Dock 共用操作面，卡片、输入框和下拉触发器共用内容面；菜单、日期面板和弹窗使用弹层规格。新页面从公共封装引入控件，组件目录里的物价卡片可直接体验记价和历史。
- **桌面能力**：用 `start.bat` 打开 Tauri 窗口，在「设置」查看账本和备份。浏览器预览中的本地账本操作会禁用。
- **对照旧界面**：浏览器开发服务可用 `npm run dev -- --mode legacy` 启动。同一端口只能运行一个服务。模式切换在 [entry.ts](../src/entry.ts)，与设置页的明暗切换相互独立。

总览在旧账检测完成后读取各领域账本。周统计和七天趋势沿用速记与在线数据，月收支按账号账本的已入账记录分别汇总梦幻币和人民币。首次进入收益或账号后，收益和点卡按原有规则自动同步到账号。总览继续从账号账本读取月收支。读取失败时，对应数据标记为「未读取」，可重试失败的来源。

工具目录与子路由共用工具清单。启动时读取活动等游戏规则，活动日历读取失败时可重试。活动提醒沿用闹钟存储，由玻璃外壳按原规则提前五分钟提醒。养成综合试算按需读取角色档案。

目录按日程、资料、游戏分列，列数随宽度调整。入口行保留名称、图标和方向标记，说明收进悬停提示，外链仍交给系统浏览器。六个详情页用同一个工具页头：返回在标题左边，当前工具的主操作和模式切换在右边，窄屏按需换行。

闹钟以紧凑玻璃卡片展示时刻、重复规则和启停状态；活动卡独立显示日期与提醒状态，提醒设置沿用物价页的玻璃弹窗与下拉；游戏资源共用玻璃搜索、分类筛选和图鉴内容面。三页直接展示主要内容，卡片按可用宽度换列，保留原有提醒、分页和预览操作。

每周闹钟的星期和封妖地图用 `GlassMultiSelect`，各项可独立勾选。封妖地图未限制时按全部地图提醒，可用「全部地图」清除限制。养成计算器的单项与综合计算用按内容排宽的 `GlassSegmented`，模式标签保持单行。

指针移入、按下或键盘聚焦 Dock 标签时预取目标页代码。点击即发起导航，若上一段仍在播放，则加速收尾，同时解析新路由。导航确认后，选中胶囊与新旧页面容器在同一帧开始，以同一条缓动曲线滑动 280 毫秒，新页内容在首帧后的任务中挂载。点左边从左侧进入，点右边从右侧进入，只移动内容区，跨多个标签直接到目标页。工具目录与详情按进入、返回两个方向入场，回到目录时恢复滚动位置。快捷入口直开弹窗时沿用弹窗自身动画。开启系统降动效时，页面直接显示；复用控件的 CSS 动效经 [reduced-motion.css](../src/styles/reduced-motion.css) 统一降级。

## 改动放在哪里

| 要改的内容 | 维护位置与用法 |
| --- | --- |
| 窗口与外观 | [LiquidApp.vue](../src/LiquidApp.vue) 管标题栏、Dock、滚动区域以及前景色、焦点色和轮廓色。明暗和壁纸选择由 [use-liquid-preferences.ts](../src/composables/use-liquid-preferences.ts) 管理；默认是 macOS Tahoe · 湖畔昼夜，随主题切换。在线壁纸无法显示且没有其他壁纸可用时也使用这一组。 |
| 字体与字号 | [liquid-main.ts](../src/liquid-main.ts) 加载资源圆体和[共享字号](../src/styles/token-typography.css)。标题、正文和辅助文字沿用现有字号档位。 |
| 玻璃材质与控件 | 从[项目封装](../src/components/liquid-glass/index.ts)引入组件。正文卡片用 `GlassCard`，操作用 `GlassButton`。要调整同类表面的填充、高光或模糊，改封装里的材质预设；跨页面的控件样式归[公共样式](../src/components/liquid-glass/style.css)。滚动条占位、**隐藏滚动条但仍可滚**、表单的小一号尺寸档、**下拉面板自适应宽度**、**glass-sheet 禁用 shadow prop**、弹窗文字和分页适用范围见[工程规范 §2.4 第 51、52、54、55、56、57 条](CONVENTIONS.md#24-样式)。 |
| 表单与弹窗 | 参考[物价编辑器](../src/views/prices/LiquidPriceEditor.vue)组合玻璃输入、日期和价格字段。[GlassDialog](../src/components/liquid-glass/GlassDialog.vue) 在打开时按窗口宽度选用居中对话框或底部面板。标题由 `label` 提供，使用 `lazy` 时内容会保留到退场结束。 |
| 收益、账号、角色、目标和工具 | 页面共用 [LiquidLedgerFrame](../src/components/LiquidLedgerFrame.vue) 和[账本玻璃样式](../src/components/liquid-glass/ledger.css)。业务区块和弹窗通过原有入口复用，收益和账号共用日汇总。角色读数行的公共布局在 [character-fields.css](../src/styles/character-fields.css)，内层表面由 `ledger.css` 映射为玻璃材质，不引入旧纸张染色。 |
| 页面与数据 | 玻璃视图负责排版和交互。查询、校验和写入沿用对应领域的 store；桌面调用统一走 `src/services/`。共享字段或保存逻辑有改动时，同时核对账簿界面的调用方。 |

## 迁移一个页面

1. 从旧页列出用户能完成的动作，沿按钮追到编辑器、确认框和保存方法。例如收益页的「上线」涉及角色选择、开始或结束计时及记录保存，这些入口应一起对照。
2. 在对应领域目录编排玻璃视图，在 `liquid-main.ts` 的 `views` 注册现有导航键。公共控件先查组件目录；本次新增可复用控件时，同步补一个可操作的演示。
3. 带编辑的页面参考物价页，在打开时记录表单初值，修改后点取消、按 Esc、点遮罩、离开页面或关窗时统一确认。底部面板有草稿时通过按钮或遮罩触发确认，下拉手势只调整面板位置。保存失败沿用原写入队列重试。启动时的旧账检测与关窗时的草稿确认、待写入数据由玻璃入口统一协调。
4. 更新上面的进度表，写清已接入的功能和仍待接入的入口。需要验收时，按[测试与验证范围](TESTING.md)选择对应场景。
