## 2. 当前基线

- 六套主题与三款字体独立切换，公共视觉规则由 styles/ 管理。
- 首页只读业务摘要；收益、账号分账；目标养成进度读取角色档案。
- 角色统一编辑器覆盖属性、师门、辅助、修炼、装备与召唤兽；统计页展示全角色档案。
- 截图按内容切换分区；空召唤兽列表支持截图建档；覆盖规则保留未识别项与装备备注。
- SQLite 为桌面数据真源；旧版数据经集中转换入口单向导入，首次空账本可自动导入。
- 日常备份、恢复、成长历史与手动检查更新已接入。版本与发布产物以配置及 GitHub Release 为准。

## 3. 近期整理

### 2026-11-16 · 账号弹窗手续费开关与角色胶囊

- 将成交总价、已扣实得的切换改为“是否扣除手续费”的两格开关，使用既有 CostSwitch，紧接价格输入框下方居中展示；移除费率与操作说明，仅保留手续费、实得金额和必要错误提示。选择“是”按成交总价自动扣费，选择“否”直接填写实得；新建卖出默认扣费，编辑默认不扣费。
- 角色下拉改为可换行的单选胶囊，移到方向、日期上方；保留“不指定”、现有角色和历史已删角色，不增加多角色记账。
- 同步调整手续费、角色单选与取消选择的烟测断言；日常档未运行测试、检查或构建。

### 2026-11-16 · 账号快捷汇总与藏宝阁实得入账

- 买入、卖出游戏币默认渠道改为藏宝阁；快捷卡按分类和方向跨渠道汇总，改用小字号一行左梦幻币、右人民币，完整金额与笔数放在悬停提示，继续遵从当前日期、角色范围。
- 查询藏宝阁官方收费规则：梦幻币卖出收取 5%，普通装备及召唤兽卖出收取 5%、最高 1000 元，不足一分按一分计。参数、来源与查询日期存入 public/game/data/gameplay.json。
- 新建适用卖出记录默认输入成交总价，展示手续费、实得并仅以实得入账；可切换“是否扣除手续费”处理特殊交易。购买、游戏内交易不自动扣费，编辑旧账不重复扣费；规则缺失或扣费后无实得时拒绝按总价保存。
- 补充跨渠道双币种汇总、收费进位与封顶、购买免扣、旧账修改和规则缺失断言，以及快捷卡与金额口径烟测；日常档未执行测试、检查或构建，未修改真实账本。

### 2026-11-15 · 收益固定价格与物价卡片联动

- 设置、修改及导入固定单价时复用同名物价卡片并追加当天价格；相同价格不重复追加，批量导入先检查记录上限再整体变更。
- 物价按当前记录回写固定价，补记旧日期不覆盖当前价；修改或删除当前记录后回退到剩余最新价，删除卡片或最后一条记录时清空固定价。
- 两边均读取成功后才联动，为已有固定单价补建缺失卡片；清除收益单价保留物价历史且重载不恢复，后续行情更新可重新同步。
- 两页保存回执等待两边写队列，定价失败时不继续记收益；补充同步、重载、批量失败与读取保护断言。
- 审查修复：收益账不可写时拒绝关联卡片的新增、改名、删卡与行情修改，防止恢复读取后旧价补回已删卡片；等待游戏物品表就绪后再补建卡片，热更新时释放旧同步监听。
- 档位：日常；未运行测试、检查或构建，未修改真实账本。
