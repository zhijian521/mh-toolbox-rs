# 发布与维护

第一版功能已完成，版本号以项目清单与锁文件的一致值为准。目标平台为 Windows 10 / 11 x64，安装包使用 NSIS，界面依赖 Microsoft Edge WebView2。其他平台没有打包与验收承诺。

## 生成安装包

本机先按 [AGENTS.md](../AGENTS.md) 设置 Windows 编译环境，再运行 `npm ci` 与 `npm run desktop:build`。打包前自动检查各清单和锁文件中的版本号，Tauri 随后构建前端与发布版。产物在 `src-tauri/target/release/bundle/nsis/`。

安装包在 Rust 构建后由 `scripts/bundle-windows.mjs` 封装，自动附带 ONNX 使用的 DirectML 与已安装 Visual Studio 的 x64 VC++ 可再分发 DLL，避免依赖开发机已有的运行库。无需手动拷贝 DLL，也不把生成的二进制加入源码仓库。

首版使用 Rust/Cargo 1.99.1，CI 和打包工作流固定为此版本。`ort-sys` rc.10 的 DLL 复制依赖旧 Cargo 输出布局，暂不自动跟随 1.100；升级工具链需要单独确认兼容性。

也可以在 GitHub Actions 手动运行「Windows 安装包」，选择需要打包的分支或标签。工作流使用锁文件构建，保存安装包、`SHA256SUMS.txt` 与源版本信息 `SOURCE.txt`，保留 14 天。它只有仓库读取权限，生成产物后由维护者下载审阅，再上传到 GitHub Releases。

## 发布版本

1. 确定版本号，同步修改 `package.json`、`package-lock.json` 的两处版本、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 和 `src-tauri/Cargo.lock` 的本项目版本。`npm run check:version` 负责核对。
2. 以准备发布的提交为准执行一次明确的「全量检查」，范围见 [AGENTS.md §一](../AGENTS.md#一验证分档默认日常仅明确要求全量检查时运行)。日常提交与静态 Review 不能代替发布验收。
3. 生成安装包，在另一用户环境或干净的 Windows 环境安装并启动，检查离线 OCR、字体、系统通知、导入导出与重启持久化。更新安装要确认原账本保留；卸载不删除账本。
4. 为通过验收的同一提交创建对应版本标签（例如 `v1.0.0`），在 GitHub Releases 写清功能、Windows 平台、数据兼容范围与尚存限制，上传安装包和校验值，再发布。

「设置 → 关于 → 检查更新」查询本仓最新正式 Release，按标签的三段版本号比较；标签与安装包版本必须一致。首次正式发布前显示「暂无正式版本」，草稿与预发布不作为更新。发现更新后打开 Release 下载页，由用户下载安装，不自动安装。

新版账本固定在 `%APPDATA%\mh-tool-rs\mh-toolbox.db`。旧 Electron v10 完整 JSON 备份可在「设置 → 数据 → 导入旧版」手动单向转换；不自动读取旧目录，也不向旧版回写。转换前展示数量与差异，确认后留存旧版原件并自动备份当前账本，再整份替换。升级前可在「设置 → 数据」导出，新版导入为整份替换；替换前自动备份。主题、字体、字号、闹钟和首页入口是本机偏好，不随账本导出。

日常访问账本时按至少 24 小时间隔留存完整备份，保留最近 14 份。可在「设置 → 数据 → 备份 → 恢复」选择日常备份或替换前备份；恢复前另存当前账本，再整份替换。备份位于同一数据目录，不替代导出到其他磁盘的备份。

## 文件保留规则

- `src/`、`public/game/`、OCR 模型、字体子集和许可属于产品输入；资源名可能由数据表与编号动态拼接，不能因为源码没有完整文件名就删除。
- 字体完整原件、图标源图和再生脚本属于维护输入。完整文楷是明确要求保留的原件，不因体积大而删除；Vite 只打包实际引用的子集。
- 单元测试、OCR 截图夹具、真窗口烟测和统一探针属于回归依据，保留。
- `.runtime/`、`dist/`、`node_modules/`、Rust `target/` 和本地工具上下文不入 Git，也不随安装包分发。它们可能包含运行实例、缓存、快照或设计稿，不作为源码清理的一部分整体删除。
- Windows 图标只保留 `tauri.conf.json` 使用的 PNG / ICO。使用 `npx tauri icon assets/icon/app-icon-1024.png` 可再生，生成器额外输出的 macOS / Store 图标由忽略规则排除。
