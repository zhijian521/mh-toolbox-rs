# 提醒助手

## 使用方式

在 Windows 桌面应用打开「工具 → 提醒助手」。初次打开时预选封妖和全部地图。已有封妖设置会带入原来的地图与窗口设置，旧设置的场景列表为空时保留封妖关闭状态；新增类型默认关闭。旧链接 `/tools/fengyao` 继续可用。

封妖、妖王、梦魇夜叉和衣冠古丘各用一张卡片，可单独开关。封妖卡片内可以展开地图列表，默认监听全部地图。妖王、梦魇夜叉和衣冠古丘直接监听所有地图，旧设置里的地图限制自动忽略。暂停只停止本次监听，总览可按上次保存的设置开启或停止。监听中可更改类型与封妖地图，关闭最后一种类型时结束当前监听。

在游戏中将聊天区单独弹出，保持窗口可见，避免最小化或隐藏。请显示系统频道，并将聊天记录停留在最新消息。监听会读取所选聊天窗口的完整画面，每次开启时重新获取窗口句柄与尺寸。修改聊天窗口尺寸后停止再开启即可。切页、工具箱窗口最小化后，后台监听继续运行；退出工具箱会停止监听。

## 公告匹配

Windows Graphics Capture 捕获所选的独立聊天窗口。一帧只运行一次本地 PaddleOCR，拼接频道签与换行后，按开启的类型匹配系统频道公告。

| 类型     | 公告识别依据                                   | 提取字段   |
| -------- | ---------------------------------------------- | ---------- |
| 封妖     | 挖塌或放出妖怪、妖魔的公告，按随包地图规则匹配 | 地图       |
| 妖王     | 挖宝敲到妖王后，妖王正在某地图寻衅闹事         | 地图       |
| 梦魇夜叉 | 受惊后携宝的梦魇夜叉跑到某地图的刷新播报       | 地图       |
| 衣冠古丘 | 衣冠古丘标签、地图坐标和墓碑出现句式           | 地图、坐标 |

封妖地图名与别名源于 [网易挖宝封妖说明](https://xyq.163.com/introduce/cg002.html)。妖王、夜叉和衣冠古丘采用 [17173 刊载的电脑版客户端截图](https://xyq.17173.com/content/09142020/222224455.shtml) 中可确认的句式。夜叉覆盖携宝龙龟播报，兼容识别文本漏掉「魇」字的情况。近版实机文案或其它分支可在取得截图后补充解析规则。玩家聊天、夜叉获奖播报和剑陵魔影标签用于排除误报。

首次成功读取为各类型建立旧公告基线。更改类型或地图时，受影响类型读取上一帧作为基线，其他类型保留当前的去重记录。重复来源离屏十五分钟后可再次提醒，四字以上角色名允许一次增删或替换以兼容 OCR 误差。封妖同地图的十秒内密集播报合并；衣冠古丘按地图与坐标去重。

## 通知和本机数据

命中后由后台发送 Windows 通知，最近提醒以标签卡片显示类型、地图、时间及可用坐标，点开可看该条 OCR 原文。截图、原文和最近提醒只驻留内存。监听类型、地图、窗口标题保存在本机偏好中。读取失败会保留原件，写入失败可重试。公告可能因快速滚动、视觉遮挡或 OCR 误读而漏读。

匹配与去重断言位于 [Rust 解析模块](../src-tauri/src/fengyao/announcements.rs)，偏好迁移和总览开启断言位于 [前端服务](../src/services/fengyao.test.ts)，生命周期及独立开关断言位于 [工具烟测](../tools/e2e/sections/08-tools.mjs)。
