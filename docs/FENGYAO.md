# 提醒助手

## 使用方式

在 Windows 桌面应用打开「工具 → 提醒助手」。初次打开时预选封妖和全部地图。已有封妖设置会带入原来的地图与窗口设置，旧设置的场景列表为空时保留封妖关闭状态；新增类型默认关闭。旧链接 `/tools/fengyao` 继续可用。

页面左侧是最近提醒时间线，右侧是监听设置；较窄时设置排在时间线下方。页头可开始或停止监听，窗口选择框下方的标签显示当前状态。设置中可分别开关封妖、妖王、梦魇夜叉、衣冠古丘、二十八星宿和宝宝幼儿园，展开封妖地图列表可调整范围，默认监听全部地图。其余五种类型直接监听所有地图，旧设置里的地图限制自动忽略。暂停只停止本次监听，总览可按上次保存的设置开启或停止。监听中可更改类型与封妖地图，关闭最后一种类型时结束当前监听。

在游戏中将聊天区单独弹出，保持窗口可见，避免最小化或隐藏。请显示系统频道，并将聊天记录停留在最新消息。监听会读取所选聊天窗口的完整画面，每次开启时重新获取窗口句柄与尺寸。修改聊天窗口尺寸后停止再开启即可。切页、工具箱窗口最小化后，后台监听继续运行；退出工具箱会停止监听。

## 语音播报

在「监听设置」点击「试听」即可试听 1.1 倍语速的 Yaoyao 女声。其他电脑若未安装 Yaoyao，会选用已安装的中文声音，不需要游戏窗口。打开「语音播报」后，总览一键开启监听也会沿用此选择。新安装和升级用户默认关闭语音。

后台只播报去重后的新公告，例如「花果山，梦魇夜叉提醒」。衣冠古丘有坐标时一并读出。同一帧内地点、类型和坐标都相同的提醒只读一次。关闭语音或停止监听会取消当前和排队中的播报。Windows 缺少兼容的中文发音人时，试听会提示安装中文语音包。

其他后台工具可在各自事件确认后调用 `crate::speech::announce(source, text)`，停止时调用 `crate::speech::cancel(source)`。每个工具使用固定且唯一的来源名，共享串行播放器；通过 `crate::speech::error(source)` 读取本来源的播报错误。

## 公告匹配

Windows Graphics Capture 捕获所选的独立聊天窗口。首次读取使用所选引擎识别整窗并建立基线。标准引擎使用 PP-OCRv4，优先用 DirectML 检测位置，CPU 识字，检测失败时可切回 CPU。标准引擎会缓存像素完全相同的文字行，停止监听时释放缓存。实验引擎使用独立的 ncnn / Vulkan 进程，处理二倍放大的画面。之后只重读有变化的区域。两处同时变化且中间有大段静止画面时，分别识别两处并保留中间的原文。局部文字碰到裁边时会扩大范围补读。局部结果仍不完整，或变化覆盖大部分窗口时，使用整窗识别。合并文字后再拼接频道签与换行，按开启的类型匹配系统频道公告。

| 类型       | 公告识别依据                                         | 提取字段     |
| ---------- | ---------------------------------------------------- | ------------ |
| 封妖       | 挖塌或放出妖怪、妖魔的公告，按随包地图规则匹配       | 地图         |
| 妖王       | 挖宝敲到妖王后，妖王正在某地图寻衅闹事               | 地图         |
| 梦魇夜叉   | 受惊后携宝的梦魇夜叉跑到某地图的刷新播报             | 地图         |
| 宝宝幼儿园 | 挖宝破坏幼儿园后，宝宝逃出、哭闹或等待领养的系统公告 | 可辨认的地图 |
| 二十八星宿 | 系统频道的星宿现身公告，合并换行和同条公告的地图     | 可辨认的地图 |
| 衣冠古丘   | 衣冠古丘标签、地图坐标和墓碑出现句式                 | 地图、坐标   |

封妖地图名与别名源于 [网易挖宝封妖说明](https://xyq.163.com/introduce/cg002.html)。妖王、夜叉和衣冠古丘采用 [17173 刊载的电脑版客户端截图](https://xyq.17173.com/content/09142020/222224455.shtml) 中可确认的句式。夜叉覆盖携宝龙龟播报，兼容识别文本漏掉「魇」字的情况。近版实机文案或其它分支可在取得截图后补充解析规则。玩家聊天、夜叉获奖播报和剑陵魔影标签用于排除误报。

首次成功读取为各类型建立旧公告基线。更改类型或地图时，受影响类型读取上一帧作为基线，其他类型保留当前的去重记录。重复来源离屏十五分钟后可再次提醒，四字以上角色名允许一次增删或替换以兼容 OCR 误差。封妖同地图的十秒内密集播报合并；衣冠古丘按地图与坐标去重。

## 通知和本机数据

命中后由后台发送 Windows 通知，最近三条提醒按时间从新到旧排列，显示类型、地图、时间及可用坐标。点击条目可在其下方展开 OCR 原文，时间线底部的「识别详情」可查看最近一次读取。「最近读取」显示实际引擎、所用帧到达后等待识别的时间以及本次 OCR 耗时（含首次加载）。新帧到达时唤醒监听，OCR 忙时保留最新帧，静止画面沿用上次读数。在「设置 → 文字识别」切换全局「快速识别（实验）」。提醒助手下次启动监听时尝试本地 ncnn / Vulkan，加载或识别失败时回到 PP-OCRv4 重读同一裁片。命中后显示该帧到匹配的延迟；开启语音后另计到 Windows 播放器首次进入播放状态的延迟。P95 取本次监听最近 32 批命中里实际开播的样本。截图、原文和最近提醒只驻留内存。监听类型、地图、窗口标题保存在本机偏好中。读取失败会保留原件，写入失败可重试。公告可能因快速滚动、视觉遮挡或 OCR 误读而漏读。

匹配与去重断言位于 [Rust 解析模块](../src-tauri/src/fengyao/announcements.rs)，偏好迁移和总览开启断言位于 [前端服务](../src/services/fengyao.test.ts)，生命周期及独立开关断言位于 [工具烟测](../tools/e2e/sections/08-tools.mjs)。
