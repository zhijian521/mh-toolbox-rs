# D07 账号页面：首批审查与优化

日期：2026-11-19。档位：日常 · 不跑验证。用户要求先按建议优化账号页面，再由用户查看调整。本批以主页面的层级、组件一致性、操作入口和历史表格为范围，关联 U02／U03／U04；不是 D07 整包完成，也不是已经通过动态验收。

用户反馈整体可以，继续调整图表卡片、页头按钮与区块小字；下表已按最终实现更新。仓库／历史采用普通按钮是用户明确选择，独立记一笔按钮已移除，十一项快捷入口和原 new 路由动作继续承接录入。相关烟测改由“其他收支”进入原记账流程，尚未运行。

最新反馈：删除主页面角色选择，摘要、快捷合计、最近记录与图表统一按日期统计全部角色。清理角色筛选 ref、候选派生、下拉及其样式；历史初始全部角色，快捷新增不再从主页面预选。记账表单与历史明细原有归属及筛选能力沿原领域契约保留。

静态定位到图表底部差异：总览局部将 --block-pad 底部设为 8px，账号／收益沿默认 18px；账号渠道卡还受 account-bottom 的 stretch 拉高。本轮将同一留白提到 blocks.css 的 chart-section，三页共用，渠道与最近记录曾改为按自身内容高度排列；最新反馈已恢复宽区等高，见下方记录。相关断言已维护，没有启动或量测真实窗口，不以源码差异代替视觉验收。

本轮按用户要求继续整理历史与仓库弹窗：历史的日期／搜索与六项下拉分行、等宽收列，两币种汇总各自按收入／支出／差额分栏；仓库分类及入仓在首行，状态／搜索／部位在筛选行，数量及多选计数归公共分页页脚。物品列表新增固定内容外框，与历史表格复用同一规则；两侧各保留 16px，空态按剩余空间居中。重置筛选不改变固定部位约束或选中集合。仓库编辑仍在同一遮罩内切页，本批未改 OCR、物品卡、编辑表单或交易持久化。

## 结论与改动

确认的规范偏差：accounts-page.css 原通过后代选择器覆盖全部 .board 的背景，不符合 CONVENTIONS §2.4-47。已移除，改为 PaperCard／LedgerSection 各调用显式 plain。原两币种摘要自绘统计结构和两张走势外壳可以复用现有组件；无需新增公共组件或设计令牌。

| 区域 | 处理与理由 |
| ---- | ---------- |
| 页头 | 历史恢复普通 PressButton；仓库使用 archive 收纳图标及 seal 主操作样式，位于最右侧。删除独立记一笔按钮，收支录入使用原快捷项或路由动作。 |
| 时间、双币种摘要 | 合入一个纯色外卡，两张 StatStrip embedded 共用 TicketCard；各币种分别展示收入／支出／差额及笔数，不合并元与万。移除主页面角色选择，仅按日期汇总全部角色，保留实际日期区间。 |
| 快捷记账 | 保留十一项业务预设和双币种小计，复用 PressTile side-tab，收紧图标、留白和行距。常驻渠道／预设说明移至 title 和完整 aria-label；游戏产出的一次性、不自动说明继续可查看。删除标题旁“当前范围 · 全部渠道”。 |
| 最近记录、渠道 | 整组移至走势之前，记账后更容易找到刚写的记录；保留最近八笔、自动来源、原编辑／详情入口与渠道图，删除标题旁笔数与“最近八笔”副文。宽区等宽等高并排，以较高内容决定卡高，窄区上下排列。渠道柱图接入 chart-in-card，移除独立厚底板，绘图区与柱体保留。 |
| 双币种走势 | 两张独立外卡合为一个 LedgerSection，各自分图、标题、坐标及图例，使用 chart-in-card；高度统一为 180px。保留全日期范围与按日／月／年汇总，汇总粒度移至标题提示。 |
| 角色分类图 | 保留通栏、币种切换、分类堆叠和键盘／悬停明细，大量角色仍沿原 fit 行为。柱图复用 chart-in-card 的透明底板、无重复外影和图例分隔规则，与总览／收益趋势一致；轴与柱体同为 180px，保留原立体柱体材质。 |
| 历史记录 | 日期／搜索独立成行，币种、方向、分类、渠道、角色、来源按六／三／两列适配；两币种各自分列收入／支出／差额。复用 record-history／record-table-frame，只有明细滚动、表头 sticky，重置用 TextButton；保留原筛选、分页与滚动记忆。 |
| 仓库弹窗 | 分类／入仓与状态／搜索／部位分组，筛选复用 record-filters，重置用 TextButton；物品区接入 record-content-frame，与历史表格共用外框规则，结果数及多选计数归分页页脚。保留同遮罩切页、返回焦点、固定部位、多选、取消与原编辑／交易链。 |
| 编辑器与异常提示 | 保留原币种先行、金额与手续费预览、角色选择及仓库关联表单。读取／保存错误、重试与自动记录详情继续使用原路径。本批没有确认需要改变的金额或表单语义。 |

布局使用 accounts 命名容器，以实际内容宽度在 760px 收为单列，极窄 480px 时币种票据读数纵向排列；金额采用公共票据的完整换行规则。近期记录、趋势与角色图的业务数据仍由原有过滤结果派生。

账号三类图表外卡与总览、收益共用 chart-section 的 8px 底部留白；图例内部间距保持公共基座，不另加重复外卡空白。
