## 3. 功能入口与完整依赖链

### 3.1 公共数据路径

桌面域的共同路径为：页面／弹窗 → 领域模型与 store → `load-data.ts`／`persist.ts` → `storage.ts` → `bindings.ts` → `lib.rs` 命令 → `store.rs` 及子模块 → 数据目录下 SQLite。数据目录仍由 `data_dir_path()` 固定为 `%APPDATA%\mh-tool-rs`。

`loadData` 只有成功读取、解析和应用数据才设置 loaded；写队列拒绝未成功加载的数据。浏览器预览使用本地存储和 `storage-sync.ts`，不是另一个桌面 SQLite 真源。以下只确认这些保护入口存在，尚未穷举错误、并发与恢复分支。

| 数据域     | 状态入口                       | IPC／Rust 落点                                                   | 主要联动                                         |
| ---------- | ------------------------------ | ---------------------------------------------------------------- | ------------------------------------------------ |
| 角色       | `characters/roster.ts`         | charactersLoad／Save → `store.rs`、`store/character_assets.rs`   | 装备、召唤兽、仓库、目标、成长历史、预算只读输入 |
| 收益       | `income/income-store.ts`       | incomeLoad／Save → `store/income.rs`                             | 物价、账号按日汇总                               |
| 在线与点卡 | `income/online-store.ts`       | onlineLoad／Save → `store/online.rs`                             | 角色、时间、点卡、账号按日汇总                   |
| 账号       | `accounts/accounts-store.ts`   | accountLoad／Save → `store/accounts.rs`；交易走 accountTradeSave | 收益／点卡自动记录、仓库物品快照                 |
| 物价       | `prices/prices-store.ts`       | pricesLoad／Save → `store/prices.rs`                             | 收益物品价格与历史                               |
| 目标       | `goals/goals-store.ts`         | goalsLoad／Save → `store.rs`                                     | 手动进度持久化，养成／组合进度读取角色档案       |
| 仓库       | `warehouse/warehouse-store.ts` | warehouseLoad／Save → `store.rs`、`store/character_assets.rs`    | 角色穿戴与账号交易                               |

跨域的特别边界：

- 角色保存经 `character_assets::save_roster` 维护名册和库存；交易经 `account_trade_save` 单个 SQLite 事务保存账号及库存。浏览器分别由 `character-assets-local.ts`、`asset-trade-local.ts` 的恢复日志保护，不把浏览器多次 localStorage 写入称为 SQLite 原子事务。
- 收益和在线是自动对账源，`accounts/daily-sync.ts` 按日排队合并；`main.ts` 关闭流程先处理草稿，再等待每日同步与持久化队列。跨日、修改历史、失败重试和关闭竞态仍留给 D06、D07、M02、M03。
- SQLite、备份信封与旧版导入是三层边界。旧文件经 `src/import/legacy.ts` 集中转换；首次空账本导入入口和设置页手动入口共用转换，不反向写旧版。备份、恢复及迁移的全部字段与事务仍待 M04。
