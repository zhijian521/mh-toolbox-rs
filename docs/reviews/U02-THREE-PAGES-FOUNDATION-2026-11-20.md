## 已实施的修复

| 问题                                           | 证据与处理                                                                                                                                                    | 边界                                                                                     |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 账号读取恢复后缺少历史对账                     | daily-sync 原只监听收益／上线数组；账号首次失败后重读不触发它们。现在监听三域共同就绪状态，恢复时统一补全部历史日期，清理已处理队列；重读中拒绝按旧快照补账。 | 对账仍仅替换稳定 ID 的自动条目，手记、仓库交易和账目精度保持。自动保存仍走账号原写队列。 |
| 超过 32 个自然日的上线时段漏算                 | sessionSlices 原固定保留 32 片，编辑和读取没有对应时长限制。现在完整切分合法时段，周月查询先裁剪到日期边界；非法或不推进的日期不进入循环。                    | 各自然日分别取整、旧多人分摊及计费快照保持。没有修改存档结构或 Rust。                    |
| 账号页看不到对账失败，最近记录可能继续展示旧值 | 原保存提示只绑定账号 writeError，最近记录仅检查长度。现在同一提示位承接保存／对账错误，优先保留普通保存的独立重试；读取失败隐藏旧记录。                       | 不再增加同类错误面板，不把源账不可读变成手记无法重试保存。                               |

长期时段取消截断后，分钟刷新改为只收集本次时钟变化覆盖的日期；休眠跨日仍补齐，回拨仍重新计算受影响日期。完整历史对账保留完整日期集合，没有以采样或截尾减少账目。

## 三页内容取舍

以下是下一批建议，尚未改动界面区块或默认展开状态。

| 页面 | 高频内容保留                                   | 可精简的具体做法                                                                                                                                                       | 原因                                                                                                                 |
| ---- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 总览 | 周月摘要、常用功能、目标、队伍及七日走势       | 新功能优先进入常用功能的功能库，沿用用户自选数量和排序；不为每个工具再加首页卡片。队伍继续展示摘要，完整编辑进入角色／收益／账号。                                     | 总览当前已删除原重复内容；跨领域摘要本身有导航价值，继续删除收益或队伍信息缺少使用证据。                             |
| 收益 | 在线双票据、角色快速上线、物品速记、今日清单   | 每日走势可收为一个可展开分析区，范围控件随区块展开；补记／上线记录／价格导入导出继续留在现有辅助位置。保留“净额不扣点卡”含义，可放到标题提示，避免在图上重复常驻说明。 | 今日统计负责对比、今日清单负责撤回，功能不同，不能仅因都显示净额就删除其中一个。分析属于低频，适合减少默认纵向内容。 |
| 账号 | 双币种摘要、快捷记账、最近记录、历史和仓库入口 | 渠道、双币种走势及角色分类归入一个可展开分析区；默认先完成记账、查看回执及近期记录。十一项快捷预设先保留，后续有使用依据再决定自选常用项或按交易／日常分组。           | 当前三个分析区域占据较多篇幅；币种与渠道／角色维度不能直接合算。快捷预设已复用同一编辑器，无需先引入新的表单。       |

推荐下一批只试点账号分析区收纳，查看效果后再决定是否把同类方式用于收益。该批应明确默认展开状态、记忆范围、键盘操作及折叠后图表资源生命周期，沿用公共按钮／材质；不直接增加“可自定义整页”的配置系统。
