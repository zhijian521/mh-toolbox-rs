# public/game/ —— 游戏资源的唯一目录

**凡是「梦幻西游本身长什么样、有什么东西」的图片、图标、数据，都放这里，别放进 `src/`。**
规则与判据见 `docs/GAME-ASSETS.md`；这里只写「往哪放、怎么换」。

```
public/game/
├── maps/   地图底图 + 清单（20 张 webp + maps.json）
├── icons/  游戏内图标（门派、任务类型、NPC …）
└── data/   游戏事实数据（门派、技能、装备、道具的 JSON）
```

## 为什么是 `public/`

Vite 对 `src/` 里的资源会**重命名加哈希**（`aolaiguo-a1b2c3.webp`），而 `public/` 下的文件
原样拷进构建产物、**文件名不变**。游戏资源要的正是这一点：

- 改一张底图 = 覆盖那个 webp，不用改代码、不用改清单；
- 清单里写的是文件名，不是哈希，所以替换后一定对得上；
- 开发期刷新页面即生效，不用重启 dev server。

代价是这些文件不经过打包器的优化（不做 minify、不加缓存指纹），也拿不到 `import` 的
类型检查。对「会随游戏版本整体更换」的资源，这个代价是划算的。

## 替换一张底图

1. 覆盖 `maps/` 里同名的 `.webp`（尺寸、比例与原图一致，否则坐标换算会整体偏移）；
2. 刷新页面。清单没变就不用动 `maps.json`。

## 加一张新地图

1. 切好图，文件名用场景的拼音（`xiliangnvgou.webp`），与 `maps.json` 的 `id` 一致；
2. 在 `maps.json` 的 `maps` 数组里加一条：

    ```json
    {
        "id": "xiliangnvgou",
        "name": "西梁女国",
        "aliases": [],
        "maxX": 200,
        "maxY": 150,
        "img": "xiliangnvgou.webp"
    }
    ```

3. `img` **只写文件名**——目录由 `src/services/ghost-maps.ts` 的 `MAP_DIR` 拼，换目录只改那一行；
4. `maxX` / `maxY` 是该场景坐标域的上限（游戏里走一遍四角读出来的），写错会让「越界贴边」判错；
5. 跑 `npm run check`——测试会读这份清单，缺图或格式错会当场失败。

## 不要放在这里

| 东西                             | 正确的家                     | 为什么                                                                 |
| -------------------------------- | ---------------------------- | ---------------------------------------------------------------------- |
| OCR 模型与字典（PP-OCRv4，16MB） | `src-tauri/models/`          | 是识别引擎的通用模型，与游戏版本无关；且要走 Tauri 的 `resources` 打包 |
| 字体、印章、应用图标             | `assets/`                    | 品牌资产，不随游戏更新                                                 |
| 测试用例、演示角色数据           | 跟着用它的页面（`views/*/`） | 它们是「为了立版式 / 跑单测」的夹具，不是游戏事实                      |

细节（命名、命名空间、JSON 约定、哪些耦合点故意没搬进来）见 **`docs/GAME-ASSETS.md`**。
