# public/game/icons/ —— 游戏内的图标与图片

门派徽记、任务类型图、NPC / 怪物头像、道具图标这类**游戏里能看到的小图**。

现在这个目录是空的：界面上的图标走 `src/components/icons.ts`（tabler 那套业务名映射），
那是**界面语言的图标**，不是游戏内的；两者不混用。等第一次真的要显示游戏图标时再往里放。

## 命名

```
<类目>-<id>.webp
```

- 类目：`school`（门派）/ `task`（任务）/ `npc` / `monster` / `item` / `map`（小地图缩略图）
- id：与 `data/` 里对应记录的 `id` 一致，小写拼音或英文短词（`school-datang.webp`）
- 中间用**半角连字符**，不用空格、不用中文——文件名要进 URL

## 尺寸与格式

- 优先 `.webp`（与底图一致，1/3 体积）；带透明通道的小图标可以用 `.png`，但不要超过 16KB
- 按**显示尺寸的 2 倍**出图：界面上显示 20px 就出 40px，缩放与高分屏都不糊
- 同一类目的图标**必须同尺寸**：一排图标里混着 40 和 48，基线就对不齐

## 引用方式

和地图一样走运行时路径，不 `import`：

```ts
const url = `${import.meta.env.BASE_URL}game/icons/school-datang.webp`;
```

若图标与数据表一一对应，把文件名写进对应的 `data/*.json`（只写文件名，目录在代码里拼
一次），别在组件里硬拼字符串——那样换一次目录要改十几处。
